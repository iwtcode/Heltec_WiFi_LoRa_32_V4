## 2. Датчик давления и температуры GY-BMP280-3.3V

Модуль на чипе BMP280 для Arduino/ESP32, версия с питанием 3,3 В.

### Характеристики

| Параметр | Значение |
|---|---|
| Модель | GY-BMP280 |
| Рабочее напряжение | 3,3 В |
| Интерфейс | I2C или SPI |
| Диапазон давления | 300–1100 гПа (±0,12 гПа) |
| Диапазон температуры | −40…+85 °C (±0,01 °C) |
| Размер модуля | 21 × 18 мм |

### Выводы

| Вывод | Назначение |
|---|---|
| VCC | Питание 3,3 В |
| GND | Земля |
| SCL | Тактирование I2C |
| SDA | Данные I2C |
| CSB | Выбор интерфейса: HIGH — I2C |
| SDO | Выбор I2C-адреса: GND → `0x76`, VCC → `0x77` |

### Примечание проекта

- В проекте используется только температура; давление не читается.
- Точность ±0,01 °C — заявление продавца. По документации Bosch 0,01 °C — это **разрешение** измерения, а абсолютная точность датчика порядка ±1 °C. Для PID-регулирования этого достаточно.
- Датчик нельзя нагревать выше +85 °C.

## 3. Драйвер двигателей MX1508

Компактный двухканальный H-мост («L298N mini»): управляет двумя DC-моторами или одним 4-проводным двухфазным шаговым двигателем.

### Характеристики

| Параметр | Значение |
|---|---|
| Тип | Двухканальный H-мост |
| Каналов | 2 |
| Нагрузка | 2 DC-мотора **или** 1 двухфазный 4-проводный шаговый двигатель |
| Напряжение питания модуля | 2–10 В DC |
| Напряжение управляющего сигнала | 1,8–7 В |
| Рабочий ток на канал | до 1,5 А |
| Пиковый ток | до 2,5 А |
| Ток ожидания | менее 0,1 мкА |
| ШИМ | Поддерживается |
| Реверс | Поддерживается |
| Защита | Перегрев, с автоматическим восстановлением |
| Размер платы | ≈ 24,7 × 21 × 5 мм |
| Монтажное отверстие | ≈ 2 мм |
| Комплектация | Модуль MX1508 — 1 шт. |

### Выводы

| Вывод | Назначение |
|---|---|
| VCC, GND | Питание модуля (2–10 В) и земля |
| IN1, IN2 | Управление каналом A (мотор A) |
| IN3, IN4 | Управление каналом B (мотор B) |
| Motor A | Выход на первый мотор |
| Motor B | Выход на второй мотор |

### Примечания

- Скорость задаётся ШИМ на одном из входов канала, направление — тем, на какой из двух входов подаётся ШИМ.
- Не подключайте моторы с током выше допустимого: при заклинивании вала или длительной работе на предельном токе драйвер перегревается.
- Питание моторов — отдельное; **минус питания объединяется с GND контроллера**.
- *Примечание проекта:* в прошивке ШИМ идёт на IN1 (IN3), второй вход канала удерживается в LOW.

## 4. Драйвер двигателя DRV8837 (Texas Instruments)

Сверхкомпактный H-мост (корпус 2 × 2 мм) для одного мотора. Для двух микромоторов нужно два модуля. Вариант DRV8838 отличается интерфейсом управления PH/EN вместо IN1/IN2.

### Характеристики

| Параметр | Значение |
|---|---|
| Тип | Драйвер двигателя (H-мост) |
| Напряжение двигателя (VM) | 0–11 В |
| Напряжение логики (VCC) | 1,8–7 В |
| Максимальный выходной ток (пик) | 1,8 А |
| Сопротивление открытых каналов R<sub>DS(on)</sub> | 280 мОм |
| Интерфейс управления | ШИМ: IN1, IN2 |
| Ток в спящем режиме | 120 нА (макс.) |
| Защиты | UVLO (пониженное напряжение), OCP (перегрузка по току), TSD (перегрев) |
| Рабочая температура | −40…+85 °C |
| Совместимость | Arduino, ESP8266, ESP32, STM32, Raspberry Pi Pico и др. |

### Выводы

| № | Вывод | Описание |
|:-:|---|---|
| 1 | VCC | Питание логики (1,8–7 В) |
| 2 | IN1 | Вход управления 1 (ШИМ) |
| 3 | IN2 | Вход управления 2 (ШИМ) |
| 4 | nSLEEP | Режим сна (активен при HIGH) |
| 5 | GND | Общий провод |
| 6 | VM | Питание двигателя (0–11 В) |
| 7 | OUT2 | Выход H-моста 2 |
| 8 | OUT1 | Выход H-моста 1 |

### Логика управления (nSLEEP = HIGH)

| IN1 | IN2 | Состояние мотора |
|:-:|:-:|---|
| 0 | 0 | Выбег |
| 1 | 0 | Вперёд |
| 0 | 1 | Назад |
| 1 | 1 | Торможение |

Скорость регулируется ШИМ на IN1 или IN2. При nSLEEP = LOW драйвер уходит в сон.

### Примечания

- Питание логики (VCC) и мотора (VM) раздельные: мотор можно питать от аккумулятора, а управлять им от 3,3 В или 5 В логики без преобразователей.
- **Не подавайте VM без VCC** — возможно непредсказуемое поведение или выход чипа из строя.
- При токе мотора более 1 А нужен теплоотвод (медный полигон на плате); проверяйте нагрев при первом запуске.
- Все защиты срабатывают автоматически.
- *Примечание проекта:* выводы nSLEEP обоих модулей соединяются вместе и подключаются к одному GPIO.

## 5. Элемент Пельтье TEC1-12706

Термоэлектрический модуль охлаждения: полупроводниковый материал между керамическими пластинами, движущихся частей нет. Смена полярности меняет местами горячую и холодную стороны.

### Характеристики

| Параметр | Значение |
|---|---|
| Тип чипа | TEC1-12706 |
| Внешние размеры | 40 × 40 × 3,75 мм |
| Номинальное напряжение | 12 В |
| Максимальное напряжение V<sub>max</sub> | 15 В |
| Рабочий ток I<sub>max</sub> | 4,3–4,6 А (номинальный при 12 В) |
| Пусковой ток | 5,8 А |
| Внутреннее сопротивление | 2,1–2,4 Ом (23 ± 1 °C, 1 кГц AC) |
| Мощность охлаждения Q<sub>c max</sub> | 55 Вт |
| Макс. разность температур ΔT<sub>max</sub> (Q<sub>c</sub> = 0) | выше 59 °C |
| Температура рабочей среды | −55…+83 °C |
| Провода | Изолированные, 18 см |

### Примечания

- **Обязателен радиатор (теплоотвод)** на горячей стороне, иначе возможны ожоги и перегрев.
- Высокая температура окружающей среды напрямую снижает эффективность охлаждения.
- *Примечание проекта:* элемент питается отдельным блоком 12 В с запасом по току (не менее 6 А из-за пускового тока 5,8 А) и общей землёй с контроллером. Драйверы MX1508 и DRV8837 для него не подходят (см. п. 7).

## 6. Комплект микродвигателей с пропеллерами (2 шт.)

Два коллекторных микромотора с двумя разнонаправленными пропеллерами: один рассчитан на вращение по часовой стрелке, другой — против.

### Характеристики

| Параметр | Значение |
|---|---|
| Диаметр двигателя | 6 мм |
| Длина двигателя | 15 мм |
| Диаметр вала | 0,8 мм |
| Длина вала | 4 мм |
| Максимальное напряжение | 4,2 В |
| Скорость вращения | 46 500 об/мин |
| Ток при 3,7 В | ≈ 0,1 А |
| Тяга при 3,7 В | 11–12 г |
| Тяга при 4,2 В | 14,8 г |
| Вес одного двигателя | 2 г |
| Длина провода | ≈ 80 мм |

### Примечания

- Направление вращения зависит от полярности подключения: если пропеллер дует «не в ту сторону», поменяйте провода местами.
- Каждый пропеллер устанавливается на «свой» мотор — иначе тяга не создаётся.
- Ток заклинивания ротора в описании не указан.

## 7. Совместимость модулей

| Связка | Условие | Результат |
|---|---|---|
| ESP32 (3,3 В) → MX1508 | Логика 1,8–7 В | ✅ Совместимо |
| ESP32 (3,3 В) → DRV8837 | Логика 1,8–7 В | ✅ Совместимо |
| ESP32 (3,3 В) → GY-BMP280-3.3V | Питание модуля 3,3 В | ✅ Совместимо |
| MX1508 → микромоторы | Питание модуля 2–10 В, мотор ≤ 4,2 В | ⚠️ Питание моторов не выше 4,2 В (аккумулятор 1S) либо ограничение скважности ШИМ |
| DRV8837 → микромоторы | VM 0–11 В, мотор ≤ 4,2 В | ⚠️ То же |
| MX1508 / DRV8837 → микромоторы | Ток 0,1 А против 1,5 А / 1,8 А | ✅ Большой запас |
| MX1508 / DRV8837 → Пельтье | 4,3–4,6 А (пуск 5,8 А) против 1,5 А (пик 2,5 А) / 1,8 А (пик) | ❌ **Не подходят**, нужен отдельный источник 12 В |
| Пельтье ↔ GY-BMP280 | Датчик до +85 °C, среда Пельтье до +83 °C | ⚠️ Датчик не должен нагреваться выше +85 °C |
| Питание моторов/Пельтье ↔ ESP32 | Раздельные источники | ⚠️ Обязательна общая земля |

## 8. Роли модулей в проекте

```
GY-BMP280  ── температура Пельтье ──►  ESP32-S3  ── ШИМ ──►  MX1508 / 2×DRV8837 ──► 2 микромотора
                                          │                                              │
                                          └── Wi-Fi дашборд, OLED                        └─ обдув горячей стороны
                                                                                              │
                                                  Блок питания 12 В ──► Пельтье TEC1-12706 ◄──┘
```

Прошивка поддерживает целевую температуру элемента Пельтье, регулируя обороты пропеллеров PID-регулятором. Распиновка и параметры драйверов — в [`README.md`](../README.md) и [`src/prop.h`](../src/prop.h).
